## Ключевые параметры [П] (ревизия 4)

| | |
|---|---|
| Основание | **1400 × 580**, труба 40×40×3, 6 регулируемых опор М12 (низ рамы 45 ± 15 от пола; габарит по опорам 686) |
| Металл | Труба 40×40×3, труба 50×50×3, калиброванный квадрат 40×40, лист 8 мм (+ лист 12 мм на площадку руля, 2 мм обычной стали на вкладыши) |
| Рулевые стойки | 50×50×3 на X = 650 (отверстия — труборез), косынки снаружи и изнутри, подкосы 40×40×3 |
| Высота площадки руля | **625…775, шаг 25** (7 положений), номинал 700; телескоп «труба 50×50 + калиброванный квадрат 40×40», 2 болта М12 на стойку, вкладыши по 4 граням + прижим М10; перестановка одним человеком (домкратный винт М16) |
| Руль вперёд-назад | **±75, шаг 25** (7 положений), гребни 50×8 в сёдлах-вилках, 4 болта М12; плавно — салазками сиденья |
| Площадка руля | 420 × 260 × **12**; база снизу или на съёмном фронтальном кронштейне (2 ряда болтов) |
| Педальная площадка | 450 × 330 × 8, угол **20…60°, шаг 10°**; ось X = **260…485, шаг 25**; высота оси **Z 120 / 170** |
| Сиденье | 2 одинаковые поперечины 50×50×3 на X = **1000…1325, шаг 25** (3 болта на конец); адаптеры без отверстий; проставки 8 мм — высота/наклон |
| Шифтер / ручник | Съёмный кронштейн на любой поперечине сиденья, справа или слева, высота **380…480, шаг 25** |
| Масса стали | ≈ 118 кг |
| Крепёж регулировок | М12 8.8 (40 / 45 / 90) в круглых отверстиях, гайки ISO 7042 (замена каждые ~5 перестановок), затяжка 80 Н·м |

## Как пересобрать

```bash
pip install cadquery matplotlib scipy ezdxf reportlab pypdf
python cad/build.py        # STEP/STL всех конфигураций + проверка столкновений
python calc/frame_fem.py   # стержневая МКЭ-модель, проверки крепежа
python cad/bom.py          # предварительная ведомость
python cad/fabrication.py  # DXF для лазера, раскрой, раскладка деталей
python cad/drawings.py     # листы чертежей и 3D-изображения
python cad/report.py       # 1_Кратко_о_раме.pdf и 2_Документация_для_изготовления.pdf
```

Все размеры — в `cad/params.py`; конфигурации регулировок — `CONFIGS` там же. Система координат:
X от переднего торца к сиденью, Y — поперёк (+ справа от пилота), Z — от пола.

## Ограничения
* Трубы смоделированы без радиусов скругления углов; сварные швы не моделировались.
* Руль, база, сиденье и манекены — условные габариты для проверки компоновки.
* Расчёт — оценочный (идеально жёсткие стыки); реальные перемещения ожидаются в 1.5–3 раза больше.
