Длины — по модели без припусков на рез; трубы показаны без радиусов скругления углов. ### Рекомендуемый запас и уточнения по крепежу
* Болты регулировок: ISO 4014 (с гладкой частью стержня в плоскости среза), класс 8.8, оцинк. — предварительно М12; длины уточнить по факту толщин после сборки. Запас +20 %.
* Под головку — стопорные клиновые шайбы-пары (Nord-Lock NL12 или аналог) или шайба ISO 7089-300HV + резьбовой фиксатор средней прочности; в соединениях с обычной гайкой — гайка ISO 7042 (цельнометаллическая самоконтрящаяся) или ISO 7040 (с полиамидным кольцом, заменять после 5–10 перестановок).
* Широкие шайбы DIN 9021 / ISO 7093 — где болт опирается на стенку трубы без накладки (в данной концепции таких несущих мест нет; держать в комплекте для адаптеров).
* Гайки приварные DIN 929 М12 — проверить по паспорту класс прочности; если ниже 8 — снизить момент затяжки до 40–45 Н·м или применить гайки класса 8 высотой ≥ 0.8d.
* Регулируемые опоры: М12, шарнирные, Ø50–60, допускаемая нагрузка ≥ 300 кг каждая.
* Вкладыши: сталь холоднокатаная 2.0 мм (набор 1.6 / 1.8 / 2.0 / 2.2 для подбора), PA6 или UHMW-PE 2 мм.
