# Предварительная ведомость материалов и крепежа (генерируется cad/bom.py)

> **Не производственная спецификация.** Количества и сечения сняты с концептуальной модели (номинальная конфигурация). Длины — по модели без припусков на рез; трубы показаны без радиусов скругления углов. Перед заказом: проверить сортамент поставщика, добавить 10–15 % на рез и брак, уточнить крепёж после выбора руля, педалей и сиденья (их крепёж здесь НЕ учтён).

### Рекомендуемый запас и уточнения по крепежу
* Болты регулировок: ISO 4014 (с гладкой частью стержня в плоскости среза), класс 8.8, оцинк., М12×40, М12×45 и М12×90. Запас +20 %.
* Гайки — ISO 7042 (цельнометаллические самоконтрящиеся) + шайбы ISO 7089 под головку и гайку; затяжка 80 Н·м; по желанию фиксатор резьбы средней прочности.
* Широкие шайбы DIN 9021 / ISO 7093 — под гайки на стенках труб 3 мм (стойки руля, стакан шифтера).
* Регулируемые опоры: М12×80, шарнирные, Ø50–60, ≥ 300 кг каждая; контргайка сверху пластины.
* Вкладыши телескопов: лазер из листа 2 мм + запасной комплект 1.5 и 2.5 мм для подбора зазора.
* Приварных гаек в регулировках нет: везде сквозные болты с гайками ISO 7042 (кроме 6 гаек М12 под опоры).
